# タイマー

試験と講演(学会発表など)の時間を計る、ブラウザで動くタイマーです。
`timer.html` 1 ファイルだけで動き、外部のファイルやサービスは読み込みません。
発表者の手元の画面に表示するほか、全画面にしてプロジェクタに映して使えます。

## 使い方

公開版は https://timer.sapp.jp で使えます。
ダウンロードした `timer.html` をブラウザで直接開いても使えます。

### 試験

1. 「試験」を選び、試験時間を入力します。
2. 「開始」を押します。
3. 試験時間が経過すると鈴が 1 回鳴り、表示が「終了」になります。

### 講演

1. 「講演」を選び、次の 3 つの時間を入力します。時間は開始からの経過時間です。
   - 予鈴(1鈴)
   - 発表終了(2鈴)
   - 質疑終了(3鈴)
2. 「開始」を押します。
3. それぞれの時間が経過すると、予鈴(1鈴)で 1 回、発表終了(2鈴)で 2 回、質疑終了(3鈴)で 3 回鈴が鳴ります。
4. 次の発表に移るときは「次の発表者」を押します。同じ設定のまま 0 から計時し直します。

### 時間の入力

「分」または「分:秒」で入力します。

| 入力 | 意味 |
|---|---|
| `12` | 12 分 |
| `12:30` | 12 分 30 秒 |

講演では、予鈴(1鈴) < 発表終了(2鈴) < 質疑終了(3鈴) の順になるように入力します。

## 表示

「カウントダウン」と「カウントアップ」を切り替えられます。計時中でも切り替えられます。

| | カウントダウン | カウントアップ |
|---|---|---|
| 試験 | 残り時間 | 開始からの経過時間 |
| 講演 | 発表終了(2鈴)までの残り時間 → 質疑終了(3鈴)までの残り時間 → 質疑終了(3鈴)からの超過時間 | 開始からの経過時間 |

- 講演のカウントダウンは、発表終了(2鈴)までの残り時間から始まります。予鈴(1鈴)が鳴っても、残り時間は発表終了(2鈴)までのまま変わりません。
- 講演では、どの鈴まで鳴ったかを画面下に ●(鳴った)と ○(まだ)で表示します。
- 数字は通常は白で、講演の質疑終了(3鈴)の後と試験の終了後に朱赤になります。

## ボタン

| ボタン | 動作 |
|---|---|
| 開始/一時停止/再開 | 計時の開始と一時停止。一時停止中は時間が進まず、鈴も鳴りません |
| リセット | 計時をやめて開始前に戻します |
| 次の発表者 | 講演のみ。同じ設定のまま 0 から計時し直します |
| 鈴テスト | 鈴を 1 回鳴らします。会場の音量の確認に使います |
| 全画面 | 操作パネルを隠して数字だけを表示します。表示部のダブルクリックでも切り替えられ、Esc で戻ります |

## 注意

- 音は「開始」か「鈴テスト」を一度押すまで出ません(ブラウザの仕様)。
- 計時中は、タブを表に出したままにしてください。タブを裏に回したり最小化したりすると、鈴が遅れて鳴ることがあります。
- 計時中は画面がスリープしないようにしています(対応しているブラウザのみ)。
- 入力した時間は、ブラウザに保存されて次回も残ります。
- ネット接続が必要なのはページを開くときだけです。開いた後は接続が切れても動きます。
- 全画面表示中は操作パネルが隠れるため、「次の発表者」などを押すときは全画面を解除してください。
